## ✨ Features

- **Key Feature 1** - Payment Gateway: Integration with local APIs like Paystack or Hubtel to support Mobile Money (MTN, Telecel, AT) and card payments.
- **Key Feature 2** - Logistics Engine: Automated shipping tier calculations based on the destination region in Ghana (e.g., Greater Accra vs. Northern Region).
- **Key Feature 3** - Performance Optimization: Image optimization for fast loading speeds over mobile data networks.

## 🚀 Getting Started

Follow these steps to set up a local copy of the project for development and testing.

### Prerequisites

Ensure you have the following software installed on your machine:
* Node.js (v18.0.0 or higher)
* npm (v9.0.0 or higher) or yarn
* Git

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd repo
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up your environment variables:**
   Create a `.env` file in the root directory and add your keys:
   ```env
   PORT=5000
   DATABASE_URL=your_database_url
   API_KEY=your_secret_api_key
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```
